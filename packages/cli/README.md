# @kunlun-js/cli

The `kunlun` command for project creation, development, builds, runtime startup, and diagnostics.
pnpm owns dependency management; this CLI is a thin project shim and orchestrator and does not
install packages itself.

This package is part of [Kunlun Engine](https://github.com/kunlunengine/core), a project of
Zixiao Laboratories.

See the [repository README](https://github.com/kunlunengine/core#readme) for usage and the engine
capability matrix.
