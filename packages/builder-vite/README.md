# @kunlun-js/builder-vite

First-party Vite Build Engine adapter for Kunlun Engine.

This package is part of [Kunlun Engine](https://github.com/kunlunengine/core), a project of
Zixiao Laboratories. The current release is an early v0.1 source preview.

See the [repository README](https://github.com/kunlunengine/core#readme) for usage and the engine
capability matrix.
